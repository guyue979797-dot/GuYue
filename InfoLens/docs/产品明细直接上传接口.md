# 商品直接上传

`POST /api/products/import/upload`

请求采用 `multipart/form-data`，文件字段名为 `file`，仅接受 `.xlsx`。
需要系统登录会话及 `X-CSRF-Token`，权限与商品档案页面保持一致。
复用页面的解析、预览检查和合并提交逻辑，存在失败记录时不导入产品及月度汇总。
本月箱装商品合并更新；历史月份只保存月度汇总。重复上传按商品编码合并，不重复新增产品。

以下 Python 示例通过正常登录获得自己的会话，不需要从浏览器提取 Cookie。
设置 `INFOLENS_URL`、`INFOLENS_USER`、`INFOLENS_PASSWORD` 环境变量后执行：

```python
import os
import re
from pathlib import Path
import requests

base = os.environ["INFOLENS_URL"].rstrip("/")
client = requests.Session()
page = client.get(f"{base}/login", timeout=30)
page.raise_for_status()
csrf = re.search(r'name="csrf_token"\s+value="([^"]+)"', page.text)
if not csrf:
    raise RuntimeError("未找到密码登录表单；代理或 OIDC 登录需使用相应认证流程")
response = client.post(f"{base}/login", data={
    "username": os.environ["INFOLENS_USER"],
    "password": os.environ["INFOLENS_PASSWORD"],
    "csrf_token": csrf.group(1),
}, timeout=30)
response.raise_for_status()
session = client.get(f"{base}/api/session", timeout=30)
session.raise_for_status()
token = session.json()["csrf_token"]
path = Path("实时库存_20261019.xlsx")
with path.open("rb") as stream:
    response = client.post(f"{base}/api/products/import/upload",
        files={"file": (path.name, stream,
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet")},
        headers={"X-CSRF-Token": token}, timeout=120)
response.raise_for_status()
print(response.json())
```

成功返回 JSON：导入记录 `id`、`filename`、新增/更新/未变化/跳过数量、
月度汇总及 `committed_at`。失败返回 400 和 `error`；行级检查失败时还返回预览详情。
未登录返回 401，CSRF 无效返回 403。请求大小遵循系统已有上传限制。
网络超时后先检查商品档案更新时间，避免不必要的重复提交和重复导入记录。

新增接口需部署更新后的 `web.py` 并重启应用后，才可在服务器地址调用。
