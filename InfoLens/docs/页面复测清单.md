# 页面复测清单

每次新功能、样式变更及组件升级执行，结果填入该次验收记录。

## 必测通用项

| 范围 | 验收 |
|---|---|
| 全局布局 | 左右8px、紧凑标题、无页面横向溢出；通知/头像与业务操作分区 |
| 筛选 | 标签可见；多条件、多选+N、清空/重置/回车；草稿与应用语义保持 |
| 表格 | 空表/短表铺满；长表内部滚动；头体对齐；拖动/双击/Home；末行、分页可达 |
| 行操作 | 文字详情/编辑、更多菜单、禁用项；权限不扩展 |
| 抽屉 | 未改遮罩关闭；修改后确认；取消确认保留值；保存期间不可关闭；失败保留；滚动底栏 |
| 可访问性 | Tab、Esc、按钮可访问名称、字段标签、焦点可见；只读可复制，错误色不被覆盖 |
| 窗口 | 1280×900、1440×900、1920×1080、390×844；记录实际CSS视口与缩放 |
| 角色 | 管理员、普通用户、超级管理员保护；无权限页面及API不可由样式变更放开 |
| 工程 | npm run check / npm run build / git diff --check；新旧代码清理 |

## 页面保持清单

- 客户：政策/线路/人员/编码/名称，查询与即时政策语义，分页，详情、编辑、修改记录、删除与批量导入。
- 商品：品牌树、库存排序、详情→编辑→取消回详情、空价格、自定义枚举、版本冲突、库存导入预览→确认。
- 雪花政策：年月、类型、启停、排序、出库/拍照/待拍/冲销/告警钻取、核销导出、导入覆盖确认、规则编辑。
- 价格与用量：月份、商品、状态、创建、金额/数量校验、结束政策确认及历史记录。
- 销售：全部筛选、排序、多选删除、月份导出、商品成本重算、商品同步结果、上传及错误反馈。
- 照片：月份/业务员/政策/终端筛选、缺失项复制、选择/全选、归档/取消归档、导出与导出记录、单条/批量任务恢复。
- 权限：账号/显示名、角色状态、超级管理员不可删除降权、密码留空保持、错误保留。
- 通知：未读数、分页、全部已读、详情错误项、嵌套关闭、用户菜单退出入口。
