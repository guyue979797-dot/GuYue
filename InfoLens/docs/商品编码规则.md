# 商品编码规则

2026-11-06，依据用户最新确认：

- 每个正常商品仅一个存货编号；编号全局唯一。待处理/下线档案可暂空，沿用原完整性规则。
- 商品编码支持多值，允许不同商品使用相同商品编码。同一商品内重复输入相同编码自动去重。
- 存货编号前端使用单值输入，接口继续采用至多一个元素的housekeeper_codes数组，以兼容销售、成本及政策关联。
- 后端数量校验和数据库唯一约束共同保证规则；商品编码去掉旧全局UNIQUE，保留商品ID+编码联合主键。
- 旧数据库迁移保留原商品与编码关系。测试环境更新前已备份；现有数据没有一商品多存货编号记录。
- 库存表按商品编码匹配时，多个有效商品共享编码将判为失败并列出冲突；禁止取第一项更新，提交前重算仍阻止歧义写入。
- 销售利润和政策成本继续通过唯一存货编号关联。

验证：全量127项后端测试通过，含共享商品编码、重复存货编号、多存货编号拒绝、旧唯一索引迁移、歧义导入无写入；前端check/build及diff检查通过。

2026-11-06 补充：政策的正常销售产品/赠送产品选项取消stock_month当月过滤，只按有效且正常状态取数；跨月不需要重传库存表才能选择商品。新增跨月、待处理/下线/删除排除测试，全量128项后端回归通过。
