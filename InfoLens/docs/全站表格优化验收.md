# 全站表格优化验收

日期：2026-11-06。需求：所有表格采用商品表格的内容自适应、自动最大宽度、自由调节并写入设计规范。

## 完成范围

- 主表：销售、商品、客户、商品政策、权限用户。
- 结果与弹窗：销售商品同步结果、商品导入预览、照片档案、照片新增记录、终端钻取（含冲销明细）、政策告警。
- 所有入口使用同一DataTable和同一列宽hook；商品专用拖动hook已删除，商品仅保留业务显示文本/上限配置。
- 五处历史原生表格经AdaptiveTable转为Arco DataTable，保留原单元格节点、条件列、按钮及回调。新功能必须直接写DataTable列配置。
- 清理旧列宽、colgroup、表格和滚动wrapper样式。普通字符串/数值统一TableText，长文本适配单元格边界。
- 政策进度是复杂可点击组合，保留400px最小宽度；其他表格默认自动80～360px，拖动64～1200px，双击/Home恢复。
