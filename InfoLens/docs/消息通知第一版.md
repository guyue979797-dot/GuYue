# 消息通知第一版

2026-10-30

## 范围

右上角铃铛、未读数量、全部/未读列表、20条分页、详情抽屉、全部已读。所有登录用户共享上传结果，已读状态按账号独立保存。上传完成后当前页面即时更新，其他页面每15秒或窗口重新聚焦时更新。

覆盖销售表、客户表、商品表（直接上传或预览确认）、政策表（预览确认）、照片链接及照片批量上传。成功预览不生成通知，最终确认后记录；预览有失败项时记录失败结果。照片后台任务在完成时记录，以任务ID去重，服务恢复后完成同样生效。

字段包括事件、成功/部分成功/失败、操作人、开始/完成时间、文件名（文件上传时）、数量汇总、现有接口提供的错误/跳过及同步明细。详情中的长列表分页展示。销售商品同步合并进销售上传通知。通知API只保存业务结果字段，不保存请求凭证或照片源链接。

## 存储和保留

独立数据库 output/_system/notifications.sqlite3，通知和详情保留60天。启动、读写时清理，后台空闲时每小时清理；关联的已读记录一并删除。清理仅作用于通知及其预览元数据，不删除业务数据。第一版从启用后记录，不回填历史上传。

## 验证

- 新增通知存储/API测试6项：共享可见、独立已读、幂等、60天删除与级联、分页、CSRF、预览和提交、失败结果、字段过滤。
- 照片单条/批量集成测试追加通知断言，销售API回归：合计9项通过。
- 前端构建、筛选组件检查、架构检查、diff检查通过。
- 独立临时库浏览器验证三种结果、详情、未读3→2、全部已读2→0、详情无横向溢出；演示数据未写入业务库。
- 全量test_web中19项通过，2项既有断言失败：商品导入updated_count预期及照片政策标签额外enabled/deleted字段；禁用通知模块后同样失败，本次未改这些业务行为。

## 第一版边界

不回填历史，不提供站外推送；详情展示上传接口已有的结果，不额外复制整份销售原表。浏览器未收到服务器响应的网络中断无法单独判定结果，以后台最终完成记录为准。
