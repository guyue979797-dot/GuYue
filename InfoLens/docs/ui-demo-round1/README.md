## 本轮范围

选择终端明细作为交互样板。复用真实项目的 FilterBar、DataTable、TableText、TableRowActions、FormDrawer 和生产 React/Arco 运行时，演示数据全部为本地生成。新增、编辑只更新内存，刷新恢复，不访问业务 API。

正式 CustomerPage 未迁移，也未部署。业务页面的权限、政策筛选、雪花业务员、批量新增、修改记录、删除及接口行为维持原实现；样板只演示核心查看、筛选、新增、编辑流程，不应被当作正式页面完整替代品。

## 开发前置检查

- 已阅读前端开发原则、前端代码重构要求、表格、抽屉和输入焦点规范。
- 仓库未找到被引用的《设计规范.md》主文档，视觉沿用现有 tokens.css 及专项规范，没有新增视觉 Token。
- 业务边界：独立样板，不调用真实接口；正式页面既有行为保留。
- 搜索并复用现有组件；继续采用 Arco Table、Pagination、Form、Input、Select、Tag、Alert、Drawer、Modal。
- 表格：沿用自动列宽、拖动/键盘调整，无固定列；数据区单一纵向滚动。
- 抽屉：small=520px 且不超过视口，单列表单、固定底栏、正文滚动、保存锁定。
- 状态覆盖：默认、加载、筛选无结果、请求失败、保存失败、只读及必填错误。
- 独立入口及作用域样式；不向 App.jsx 和 legacy.css 添加实现。
- 回滚：删除样板目录和构建/预览脚本；公共组件小改动可独立回滚。

## 第四次调整：简洁工作界面（2026-11-08）

设计约束：界面不依赖标语、解释段落及次要标签才能理解；必要信息通过标题、字段、操作和布局表达。保留业务状态、校验错误、失败重试和防止丢失修改的保护。

| 决定 | 用户体验 | 开发者体验 | 智能体体验 |
|---|---|---|---|
| 标题与数量只出现一次 | 减少重复信息 | 删除重复计数和筛选状态派生逻辑 | 单一标题、唯一客户数量可访问名称 |
| 筛选和表格直接排列，去掉卡片与阴影 | 更早看到数据 | 一个 Flex 高度链替代视口减常量的布局 | 清晰的筛选/列表 region |
| 保留字段名和标准按钮 | 不靠说明理解操作 | 复用 FilterBar / DataTable / FormDrawer | 稳定的 label、role 和控件名称 |
| 中性色和文字状态，去除标签装饰 | 减少颜色竞争 | 使用已有 Token；不改 Arco RGB 变量 | 状态以真实文本表达，不依赖颜色 |
| 原生 details 收起演示控制 | 默认页面只呈现工作内容 | 不引入新状态或弹层实现 | 标准 summary 可键盘展开，原测试入口保留 |
| 保留错误、验证及保存保护 | 避免丢失输入及重复提交 | 继续使用原有组件行为 | 可读取错误、禁用及输入状态 |

本轮没有增加依赖，没有修改业务 API 或正式页面。全局组件默认行为维持上一轮。

## 第五次调整：列宽撑满容器（2026-11-08）

按用户最新要求更新公共DataTable，业务页面不另写算法。内容测量决定基准宽度；不足容器时按比例分配剩余空间，优先保持手动列宽；所有列均手动设置时以存储宽度为基准补足。超过容器时在表格内横向滚动。同步更新《表格设计规范》1.1，取代旧的“不撑满”约定。

复用列宽hook调用纯分配函数，通过ResizeObserver读取可用宽度，扣除垂直滚动条和选择列。表头表体继续使用同一份明确列宽。demo补接既有useContainerHeight，修复未设置scrollY时末行被容器裁切的问题。

验证：1440px窗口可用1232px、表格1232px，8列头体左边界误差均为0；1920px窗口可用1712px、表格1712px，筛选及空结果仍铺满；手动调整342→358，筛选后保持358，双击恢复当前数据宽度210；390px窗口内部可用374px、内容1152px，内部横向滚动且页面无溢出；第二页首行和末行均可打开详情。最终控制台无捕获错误。

纯函数检查覆盖比例分配、宽表不缩小、手动优先、全手动、空列、整数舍入及选择列预留。npm run check、npm run build、npm run demo:build通过。截图fill-columns.png。真实Mac拖动手势与生产页面全量回归尚未执行。
