# 全站新增、详情与表单抽屉改造验收

2026-11-06。范围由用户明确授权：所有模块的新增与详情以商品右抽屉为标准，纳入未来设计规范。

## 改造范围

- 商品：现有详情/新增/编辑抽屉迁入共用AppDrawer，保留同一抽屉内详情编辑切换；导入预览改为抽屉。
- 客户：新增、编辑、批量新增、修改记录改为FormDrawer；命令式Modal.info详情改为声明式详情抽屉，支持直接进入原编辑流程。
- 用户权限：新增、编辑改为FormDrawer，不扩展原管理员权限。
- 商品政策：新建价格政策、政策标签新增/编辑、政策详情、告警与终端钻取、出库导入预览改为抽屉。
- 销售：其他字段详情、商品同步结果及月度成本重算表单改为抽屉。
- 照片：新增单链接/批量提取、归档、照片档案、提取记录、报错信息、缺失终端、复制编码均使用抽屉。
- 消息通知：列表及详情迁入共用AppDrawer。
- 删除/结束政策等短确认、照片移除标签确认保留；图片预览和下载流程保留。

## 共用实现与清理

新增AppDrawer/FormDrawer，删除旧FormModal；业务代码不再直接使用Drawer或Modal.info。尺寸520/720/920px，受100vw约束；内部scroll层flex收缩，标题、底栏固定，正文滚动。显式使用Arco getChildrenPopupContainer将子弹层挂body，避免Drawer自身默认挂内容区造成裁切。

保存/导入使用统一loading与disabled语义：底部取消、关闭图标、Esc及重复提交均锁定。保留onOk导入兼容、footer=null、原字段校验与业务回调。照片后台恢复流程不变。

删除旧Modal尺寸、Header/Title/Body样式；详情字段改为左标签右值，完整换行。文档及frontend/AGENTS.md已登记全站修改范围与设计标准。

## 固定底栏与长内容滚动复检

- 实测发现Arco焦点锁定span未传递高度：711px高视口中，客户表单scroll层被撑至1001px，底栏超出可视区域。保留焦点锁定，为其包装层补齐flex、高度和min-height约束，正文取消原100%高度；共用底栏增加置底定位、不透明背景及层级。
- 客户新增修复后正文可视598px、内容888px；实际滚动290px后底栏底边仍为711px，背景页面滚动为0。商品新增正文598px、内容754px，底栏同样贴合711px底边。
- 政策新增在533×711 CSS视口下正文598px、内容1054px，无横向溢出，内部滚动时底栏保持可见。以上均取消表单，未写入业务数据。
- npm run check、npm run build、git diff --check通过；公共样式约束加入check:drawers，所有使用AppDrawer/FormDrawer的模块共用修复。
